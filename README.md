# Candlewood Interiors

The Candlewood Interiors marketing website. Built with Next.js, TypeScript, and Tailwind CSS.

## Publish it (one click)

This button creates a free Vercel account (if you don't have one) and deploys this
exact code, automatically, with zero setup:

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https%3A%2F%2Fgithub.com%2Fchrisjaillet2007%2FCandlewood%2Ftree%2Fclaude%2Fwebsite-creation-oafvp1&project-name=candlewood-interiors&repository-name=candlewood-interiors)

No environment variables, API keys, or database are required — click it and it deploys.

Once it's live, add `candlewoodinteriors.com` as a custom domain from the Vercel
project's **Settings → Domains** tab.

## Run it on your own computer

```bash
npm install
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000).

## Project structure

- `src/app/` — pages (Home, Portfolio, Services, About, Process, Journal, Contact)
- `src/components/` — reusable UI, layout, and section components
- `src/data/` — site content (projects, services, journal posts)
- `public/brand/` — the official Candlewood logo assets
